# AI Use

First of all, the search uses a hybird model to use BM25 and density search. Part of density search is transformer models. So in that way, this is an AI-powered application.

Currently, this codebase is 75% from coding templates, 20% my code, and 5% AI generated code when I get stuck. I will testify that I understand the code of the latter 25%. My today philosophy is that AI can be a learning tool but not should be used as only the learning tool.

Also I don't know how much AI is being used in the dependencies.
